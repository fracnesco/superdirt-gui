# SuperDirtGUI, in detail

The [README](../README.md) is the short version: install it, open the window,
play it from Tidal. These pages are the long one - what each part does, why it
does it that way, and what SuperDirt does underneath.

| page | what it covers |
|------|----------------|
| [architecture.md](architecture.md) | how it is built without changing SuperDirt: the classes, reading a file, how a change reaches the window, who frees what, what is optional |
| [the-mixer.md](the-mixer.md) | what an orbit's signal goes through, in order: tracks, inserts, return tracks, feedback, levels, solo, meters, recording |
| [the-window.md](the-window.md) | every button, menu, key and gesture of the control window |
| [library.md](library.md) | every synth, module, player and global effect, parameter by parameter (generated by [make-library.scd](make-library.scd)) |
| [drums.md](drums.md) | the drum machine: fifteen voices with presets, the parameter words they share, how loud each one is and how that was measured, writing a drum voice, the rendered banks, `sdglayer` |
| [writing-content.md](writing-content.md) | the four kinds of content file, the header the window reads, new... and reading a file again on save |
| [sample-players.md](sample-players.md) | how an event gets to a player, what arguments it receives, and how to write one |
| [sample-editor.md](sample-editor.md) | the editor window: trimming, the beat grid, the slicer, what the numbers mean, what a save writes |
| [sample-tags.md](sample-tags.md) | the analysis of every sample: tags, bpm, key, sorting the explorer by them, picking samples by them from Tidal |
| [sync.md](sync.md) | long samples on one tempo and in one key, written as Tidal code with loopAt, chop and speed: the arithmetic, the key, the window |
| [sessions.md](sessions.md) | the mixer saved under a name: what is in a session, what saving and loading do, in order |
| [superdirt-notes.md](superdirt-notes.md) | what SuperDirt, scsynth, Qt and the plugins actually do, each with how it is known |
| [testing.md](testing.md) | how this is checked without anybody listening, and what is left for a person |

The help files - select a class name and press cmd/ctrl + d - are the reference
for every method; these pages are the explanation around them. The
[Tidal examples](../examples/tidal/) are where to go to hear any of it: files
0 to 23 one thing at a time, files 24 to 37 whole pieces of nine parts each,
one style each, meant to play at once.
